# NumPy Matrix Operations

## Overview

This project demonstrates basic matrix operations using Python and NumPy. It creates two matrices and performs addition, subtraction, matrix multiplication, and transpose operations.

## Objectives

- Create matrices using `numpy.array()`.
- Perform matrix addition and subtraction.
- Understand matrix multiplication using the `@` operator.
- Calculate matrix transposes using `.T`.
- Understand matrix dimensions and shapes.

## Technologies Used

- Python 3
- NumPy
- Visual Studio Code

## Installation

Install the required dependency:

```bash
python -m pip install -r requirements.txt
```

## Run the Project

```bash
python matrix_operations.py
```

## Matrices Used

Matrix A:

```text
[[1, 2],
 [3, 4]]
```

Matrix B:

```text
[[5, 6],
 [7, 8]]
```

## Operations Performed

1. Matrix addition
2. Matrix subtraction
3. Matrix multiplication
4. Transpose of Matrix A
5. Transpose of Matrix B

## Key Learning

Matrix addition and subtraction operate element by element. Matrix multiplication calculates row-by-column products and sums. Transposition exchanges rows and columns.
